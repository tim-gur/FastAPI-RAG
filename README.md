# Цели и использованные технологии
Данный проект является FastAPI приложением, использующее LLM модель и RAG систему для выполнения трех задач:
- ответ на вопрос пользователя на основе заранее подготовленных данных, загружаемых в векторную базу данных qdrant
- создание задачи и ее хранение в базе данных sqlite
- добавление комментария к задаче
В зависимости от запроса пользователя модель принимает решение для совершения необходимого действия.  
Весь сервис запускается через Docker.

# Архитектура системы:  
- FastAPI приложение с главным эндпоинтом, принимающее все запросы пользователей
- база данных qdrant, которая при инициализации переводит тестовые файлы в векторный формат
- база данных sqlite, хранящая информацию по задачам
- база данных redis для сохранения state агента
- агент на основе langchain, работающий на модели llama 3.1

# Описание основных файлов:
- **app/main.py**: FastAPI приложение
- **app/logger.py**: логирование, записывающее логи в локальные файлы
- **app/qdrant.py**: инициализая базы данных qdrant и эмбеддинг текстовых файлов
- **app/schemas.py**: валидация и инициализация state для агента
- **app/session.py**: сохранение state и инициализация sqlite
- **docs/**: текстовые файлы для RAG
- **tests/**: тестирование 

# Шаги для воспроизведения проекта
1. Воссоздание среды:
```bash
    pip install -r requirements.txt
```
2. Запуск сервиса:
```bash
   docker compose up -d
```
3. Скачивание моделей:
```bash
   docker compose exec ollama ollama pull llama3.1
   docker compose exec ollama ollama pull nomic-embed-text
```
4. Тестирование:
```bash
    pytest tests/ -v
```
5. Тестовые запросы:
```bash
    python3 test_requests.py
```
