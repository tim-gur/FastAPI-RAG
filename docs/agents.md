# Agent Basics
ИИ-агенты (AI Agents) — автономные компьютерные программы на базе больших языковых моделей (LLM), которые не просто отвечают на вопросы как чат-боты, а умеют ставить задачи, планировать шаги и использовать внешние инструменты (браузер, базы данных, API) для решения сложных многоэтапных задач.
