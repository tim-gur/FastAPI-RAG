# RAG System
RAG (Retrieval-Augmented Generation), или генерация с дополненной выборкой — это технология, которая подключает большую языковую модель (LLM) к внешней базе знаний.Простыми словами, вместо того чтобы заставлять нейросеть отвечать только по памяти (которая у неё ограничена датой окончания обучения и склонна к «галлюцинациям»), RAG позволяет ей «подглядывать» в актуальные документы перед тем, как выдать ответ.
